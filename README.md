Entry for the [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2) competition "One-Line Laugh Sprint".

`main.py` (Python 3.13, pure standard library, deterministic, no network)
writes one funny line about everyday life to `entry.txt`: a houseplant
dies in a week, and the empty pot left behind sits on the sill like a
tiny, silent performance review of the owner's entire adult life.

Run it with:

```sh
python3 main.py
```

It prints the character count (Unicode code points, 132 of the 200
allowed) and the SHA-256 of `entry.txt`.
